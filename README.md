# Vitalis Health — Complete AI Personalized Health & Diet Companion

A modern, production-grade web application for personalized health, BMI calculation, nutrition planning, daily habit tracking, and AI-powered health guidance.

## Live Demo Link
Open in any mobile or desktop browser:
https://vinayakshingare-ops.github.io/agentic_nayak/

## Features
- **Accurate Health Calculations**: Mifflin-St Jeor TDEE, BMR, and interactive BMI gauge.
- **7-Day Dynamic Meal Planner**: Tailored breakfast, lunch, dinner, and snacks with one-click meal swaps.
- **Daily Habit Trackers**: Water, weight, steps, sleep, and diet adherence tracking.
- **AI Health Assistant**: Intelligent interactive conversational guidance based on user metrics.
- **Grocery List**: Auto-categorized ingredients list with interactive checkboxes.
- **Responsive Mobile First UI**: Clean modern design with bottom navigation on mobile devices.

## Running Locally
```bash
npm install
npm run dev
```
Open http://localhost:3000
